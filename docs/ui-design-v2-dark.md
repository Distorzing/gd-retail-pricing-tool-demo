## 关键组件

- 报价卡：44px 负字距大数字（tabular-nums），推荐卡琥珀渐变描边 + 发光 + 渐变价格字 + 「★ 推荐」浮动徽章；胶囊 KPI 标签（绿=利润，灰=中性）。
- 公式条：code 用蓝色半透明底，等宽字体。
- 表格：11px 大写表头，发丝级行分隔 rgba(255,255,255,.05)，hover rgba(255,255,255,.03)，E[C] 行蓝底。
- 表单：深色底输入框，聚焦环 rgba(10,132,255,.35)；单位选择为分段控件（segmented）。
- 状态：校验通过绿底卡 / 失败红底卡 / 警告琥珀底卡；红线预警为暗红半透明横幅。
- 图表：网格 rgba(255,255,255,.08)，文字 #98a0b3，序列色 #3f9bff / #ff9f0a，柱图红 #ff6961 / 绿 #30d158。
- 打印版报价说明保持浅色（省墨、便于签字归档），不随界面暗色。

## 动效（apple-design §1/§4/§14）

- 按压即反馈：按钮/卡片 :active scale(0.96~0.985)，100ms。
- hover：卡片 translateY(-3px) + 阴影加深，cubic-bezier(.2,.8,.3,1)，弹簧感无 overshoot。
- @media prefers-reduced-motion: reduce → 去位移/缩放；prefers-reduced-transparency: reduce → 毛玻璃转实色。
