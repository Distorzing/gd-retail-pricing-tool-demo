# 广东单客户固定价零售定价工具 V1.3

面向售电公司客户经理/交易人员的网页定价器：**导入单一客户 8760 用电曲线 → 三部制成本模型 → 输出峰平谷固定价（P峰/P平/P谷 + 等效平均签约价）三档报价**，含 VaR/CVaR 风险审批门槛与正式报价闸门。

全部计算在本机浏览器完成，**数据不出本机**；除本地 vendor 的 SheetJS 外无外部依赖，离线可用。

## 快速开始

```bash
cd pricing-tool
python3 -m http.server 8791
# 浏览器打开 http://127.0.0.1:8791/index.html
```

使用路径：① 报价输入与校验 →（可点「生成演示曲线」体验）→ 填 W / W_LT、确认用户分类与单位 → 校验通过 → ② 开始测算 → 自动跳转三档报价。

## 核心模型（V1.2/1.3）

```
QLT,t = r × Q × g_t                        # 中长期标准代理配置（非真实合同匹配）
QDA,t = Q × g_t × (1+ε_s)                  # 日前申报代理预测（统调形状+负荷误差）
Q实,t = q_t                                # 客户 8760 实际曲线

C批发,s = Σt[QLT×PLT + (QDA−QLT)×PDA + (Q实−QDA)×PRT] + C分摊,s − R返还,s
C总,s   = C批发,s + C结算,s(SR) + C信用服务,s(O) + 结构风险准备金（估算）

P平,k = [Quantile(C总, qk) + Mk] / K       # 三档：q=95/90/80%，M=20/10/5 元/MWh
P峰,k = f1×P平,k；P谷,k = f2×P平,k；等效平均签约价 = P平,k × K
K     = f1×α峰 + α平 + f2×α谷

Πs,k  = 等效价 − C总,s                      # 元/MWh
亏损概率 = Σw_s[Πs<0]；VaRα / CVaRα 按情景权重计算（不假设正态分布）
```

- W 为**日前价格锚点**、W_LT 为**中长期均价锚点**（可空，默认取 W）；价格形状由情景曲线维护，避免年度均价与曲线价值重复计算
- 曲线暴露分列展示：日前曲线暴露 CV日前、实时偏差暴露 CV实时（含负荷误差），同一量差不重复计入成本
- **冲单价推荐门槛**：预期毛利 ≥ 最低毛利、亏损概率 ≤ 上限、CVaRα ≤ 限额，三门全过才显示「★ 推荐」，否则显示「需审批冲单价」
- 主单位元/MWh；元/度 = ÷1000；分/度 = ÷10

## 峰谷规则（V1.1）

- 零售结算系数（广东现货结算细则 2025 修订 §8.1.5，暂定）：其他地市 1.70/0.38、深圳 1.53/0.32、蓄冷 1.65/0.25、深圳低压 1.3553/0.2894
- "峰谷用户"按档案声明，不按曲线推断；非原峰谷用户不进入峰谷平衡机制（回退单一固定价）
- 「深圳低压+蓄冷」等重叠组合：必须人工选择系数，未选择时阻止正式报价导出
- 深圳第二层输配/终端峰谷比价表（11 行）单独维护、仅展示，不替代零售结算层
- 峰谷平衡原始暴露 C=W×[(f1−1)Q峰−(1−f2)Q谷]、尖峰电能量/输配加价、系统运行费、市场化分摊——全部单列，不计入三档价

## 正式报价闸门（以下任一触发 → 仅内部测算，阻止正式报价说明导出）

峰谷属性重叠未确认 / 待核验；规则版本失效（有效期至）；结构风险准备金未审批；VaR/CVaR 风险门槛未审批。
审批在参数管理中由授权人员执行（写入审批人与时间，版本留痕）。JSON 快照始终可下载（含闸门状态标注）。

## 数据输入

客户曲线支持：Excel 直接粘贴、**上传 .xlsx/.xls**（自动识别日期/时刻/用电量列，兼容文本日期与 Excel 日期序列号）、上传 CSV/TXT。列结构：三列（日期、时刻、用电量）或两列（日期时间、用电量）。校验：报价年度 8760 点完整、日期+小时唯一、非负；失败即阻止，不补数。

用户分类字段（V1.1）：合同价口径（峰平谷系数结算/全时段同价）、供电营业区、原峰谷政策状态、低压标识、蓄冷认定、电压等级、供电计量方式、用电类别、容量。

样例文件：`examples/sample-customer.csv` 与 `examples/sample-customer.xlsx`。

## 参数管理（⑥ 页签）

价格情景（权重/价格因子/实时价差因子/负荷误差/分摊/返还/SR/O、曲线替换、增删）、统调曲线替换（自动归一）、档位 q+M、零售峰谷系数、峰谷/尖峰时段表、结构风险准备金与风险门槛（含审批）、到户账单层（单价+承担方）、深圳终端表。**权重合计≠100% 禁止保存**（±0.05% 显示舍入自动归一）；所有编辑另存新版本，旧版本与快照版本号保留追溯。

## 导出与留痕（⑤ 页签）

每次测算自动保存快照（本机 localStorage，最多 50 条）：输入、用户分类、参数版本、成本模型与审批状态、代理假设、全部中间结果（三层成本/峰平谷价/VaR/CVaR/门槛）、风险提示、闸门状态。「生成报价说明」输出打印版（可另存 PDF），含「模型测算价，不替代正式结算单」声明。
